## 📖 درباره پروژه
پروژه **Freenetvt** یک اکوسیستم جامع و هوشمند برای ارائه کانفیگ‌ها، مسیر‌یابی بهینه و مدیریت ابزارهای عبور از محدودیت‌های شبکه است. هدف این پروژه دسترسی آزاد، پایدار و پرسرعت به اینترنت جهانی با بالاترین سطح امنیت و پینگ بهینه می‌باشد.

---

## 🚀 پنل مرکزی و زیرشاخه‌ها (دسترسی سریع)

پنل مرکزی پروژه (نسل جدید اینترنت آزاد) به عنوان هسته اصلی مدیریت ترافیک عمل می‌کند و زیرشاخه‌های تخصصی آن به شرح زیر هستند:

1. 🌐 **پنل مرکزی (نسل جدید اینترنت آزاد)**
   * **توضیحات:** پنل اصلی و جامع مدیریت، پایش و تجمیع تمامی سرویس‌ها و ترافیک‌های شبکه.
   * [ورود به پنل مرکزی](https://sub.freenetvt.ir)

2. ⚡ **پنل سیم‌باکس (Sing-box)**
   * **توضیحات:** زیرشاخه تخصصی هسته مدرن **Sing-box** برای کانفیگ‌های اتوماتیک، تست پینگ زنده و مسیریابی هوشمند.
   * [ورود به پنل سیم‌باکس](https://sub.freenetvt.ir/singbox)

3. 🔌 **پنل ویتوری (V2ray)**
   * **توضیحات:** زیرشاخه پروتکل‌های کلاسیک و پرسرعت **V2ray / VLESS** برای دستگاه‌های مختلف.
   * [ورود به پنل ویتوری](https://sub.freenetvt.ir/v2ray)

4. 🛡️ **پنل وایرگارد (WireGuard)**
   * **توضیحات:** زیرشاخه پروتکل پرسرعت، مدرن و سبک **WireGuard** برای اتصال پایدار و تونلینگ با حداقل تأخیر (پینگ).
   * [ورود به پنل وایرگارد](https://sub.freenetvt.ir/wireguard)

5. 🔒 **پنل اوپن‌وی‌پی‌ان (OpenVPN)**
   * **توضیحات:** زیرشاخه اتصال امن، پایدار و رمزنگاری‌شده بر پایه پروتکل کلاسیک **OpenVPN**.
   * [ورود به پنل اوپن‌وی‌پی‌ان](https://sub.freenetvt.ir/openvpn)
